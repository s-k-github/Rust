Problem Statement

This project is a Rust-based implementation of a simplified version of the Unix `grep` utility. The goal is to build a command-line tool that searches for lines matching a given pattern within one or more input files. The tool should support:

* Basic exact or partial string matching
* Case-sensitive and case-insensitive options
* Regular expression matching (optional)
* Recursive search through directories (optional)
* Display of matching lines with optional line numbers

This tool is useful for efficiently scanning files or logs to extract meaningful information based on user-specified patterns—offering performance and safety guarantees through Rust’s type system and memory model.
